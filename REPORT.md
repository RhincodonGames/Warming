## Challenges & Fixes

### 1. Time Management → Prioritization & Scheduling
- **Challenge:** Managing time effectively while balancing this project with my other classes.
- **Fix:** Implemented task lists on index cards. I tried to break features down into manageable chunks ordered on priority for the project requirements.

### 2. Mob Interactions (Receiving/Dealing Damage) → Debugging & Simplified Mechanics
- **Challenge:** Implementing reliable combat systems where mobs and the player correctly deal and receive damage.
- **Fix:** Centralized health and damage logic, added debug logs to track hits, and standardized the use of colliders and triggers for interactions.

### 3. Unity Terrain Tool → Hybrid Approach
- **Challenge:** Difficulty creating detailed landscapes using Unity Terrain Tools.
- **Fix:** Combined the Terrain Tool for broad landscapes with hand-placed 3D models for details to achieve the look closer to what I wanted.

### 3. 3D Modeling (Blender) → Simplified Workflow
- **Challenge:** Limited proficiency in Blender led to manually creating models in Unity, which increased development time and caused conflicts with combat systems.
- **Fix:** Got lots of experience working with tags and parent vs child gameObjects to later simplify combat system mechanics.
