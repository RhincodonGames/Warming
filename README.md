# Warming

## How to Run
1. Download the latest release from the **Releases** section (to the right of this screen).
2. Extract the downloaded '.zip' file.
3. Run the executable named "Warming"

## Features
- Play as a polar bear in a snowy tundra with smooth movement mechanics
- Attack trees, boulders, and icebergs to gather resources for equipment crafting.
- Fight Ringed Seals and catch Common Fish to gather food and survive the harsh survival envrionment
- Gather berries to sustain your hunger and regain health
- Navigate an intuitive but complex inventory system/pause menu
